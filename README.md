# Student Management System

A CRUD-based Student Management System developed as part of the web application development assignment.

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Django
- Django REST Framework
- SQLite

## Features

- Add student
- View student details
- Update student details
- Delete student
- Search students
- Email validation
- Year validation
- Duplicate email validation
- REST API integration

## CRUD Operations

- Create – Add a new student
- Read – View student records
- Update – Edit student information
- Delete – Remove a student record

## Database

SQLite is used to store student records.

## API

The application uses Django REST Framework to provide RESTful API endpoints for student management.
